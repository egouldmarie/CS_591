# Large Assignment Prototype

This is a javascript implementation of the prototype of Large Assignment #1. It can be installed with yarn or npm.

## Install and Run

You can find yarn [here](https://classic.yarnpkg.com/lang/en/docs/install/).

After downloading the repository, navigate to the CS_591 folder and run the command:

```
yarn
```

or

```
yarn install
```

Once dependencies have finished installing, start the development server with the command:

```
yarn start
```

The website is locally hosted at [`http://localhost:3000`](http://localhost:3000/).
